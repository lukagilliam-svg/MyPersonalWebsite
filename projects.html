Bank Account Tracker (Python)

A small Python application that simulates tracking a checking account across 7 days. It records daily transactions (deposits/withdrawals) and prints a running balance. Useful for practicing file I/O and simple logic.

# Example snippet (Python):
transactions = [("Mon", -24.50), ("Tue", 150.00), ("Wed", -12.30)]
balance = 500.00
for day, amt in transactions:
    balance += amt
    print(day, "->", balance)

Status: Prototype
